# Assistant Skill Set

## Code Reading & Navigation
- Read and understand files across entire codebases in any programming language
- Search for symbols, patterns, and references using regex and glob patterns
- Navigate complex project structures and understand dependencies

## Code Writing & Editing
- Write new code in any mainstream programming language (Python, JavaScript/TypeScript, Go, Rust, Java, C/C++, Ruby, PHP, Swift, Kotlin, and more)
- Edit existing files with precise, targeted replacements
- Refactor code: rename variables, extract functions, restructure modules
- Create new files and project scaffolding from scratch

## Debugging & Problem Solving
- Analyze error messages, stack traces, and logs
- Identify root causes of bugs through code analysis
- Suggest and implement fixes for runtime and compile-time errors
- Trace data flow and control flow through complex systems

## Shell & Terminal Operations
- Execute shell commands (build, test, lint, install dependencies, etc.)
- Run package managers: npm, pip, cargo, go, maven, etc.
- Manage Git operations: commit, push, pull, branch, merge, rebase
- Use the GitHub CLI (`gh`) for issues, PRs, CI/CD logs, and more

## Project & Dependency Management
- Install, update, and manage project dependencies
- Configure build tools and task runners
- Set up linting, formatting, and testing infrastructure
- Create and maintain configuration files (e.g., tsconfig, webpack, Docker, CI/CD)

## Testing
- Write unit tests, integration tests, and end-to-end tests
- Run test suites and interpret results
- Fix failing tests and improve test coverage

## Git & Version Control
- Stage, commit, and push changes with descriptive messages
- Create and manage branches
- Resolve merge conflicts
- Review diffs and understand change history

## Documentation
- Write and update README files, docstrings, and inline comments
- Create technical documentation and API references
- Generate changelogs and migration guides

## Web Development
- Frontend: HTML, CSS, JavaScript/TypeScript, React, Vue, Angular, Svelte
- Backend: Node.js, Express, Django, Flask, FastAPI, Spring Boot, Rails
- Databases: SQL (PostgreSQL, MySQL, SQLite), NoSQL (MongoDB, Redis)
- Modern UI/UX design with responsive layouts

## DevOps & Infrastructure
- Write and edit Dockerfiles and docker-compose configurations
- Configure CI/CD pipelines (GitHub Actions, GitLab CI, etc.)
- Manage environment variables and secrets
- Work with cloud platform configurations

## Data & Notebooks
- Edit Jupyter notebooks (Python, R, SQL, etc.)
- Data analysis and manipulation with pandas, NumPy, etc.
- Visualization with matplotlib, seaborn, plotly, etc.

## Languages Supported (non-exhaustive)
Python, JavaScript, TypeScript, Go, Rust, Java, C, C++, C#, Ruby, PHP, Swift, Kotlin, Scala, Haskell, Elixir, Dart, Lua, R, SQL, Shell/Bash, HTML, CSS, YAML, JSON, TOML, Markdown, and many more.
